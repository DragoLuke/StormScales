===============================================================================
                            3. TRANSMISSION COMMANDS
===============================================================================

TX PC - Generate EAS Alert via HackRF
-------------------------------------------------------------------------------

# Basic transmission command:
hackrf_transfer -t DMO_National.iq -f 162550000 -s 2000000 -x 25 -a 0

-------------------------------------------------------------------------
| Flag     | Value       | Meaning                                      |
|----------|-------------|----------------------------------------------|
| -t       | .iq file    | IQ payload from eas_generator.py             |
| -f       | 162550000   | Frequency = 162.550 MHz (NOAA Weather Band)  |
| -s       | 2000000     | Sample rate = 2 MSPS                         |
| -x       | 25          | VGA gain = 25 dB (range: 0-47)               |
| -a       | 0           | Amp = OFF                                    |
-------------------------------------------------------------------------

TUNING NOTES
-------------------------------------------------------------------------------
• Weak signal → Increase -x (max 47)
• Distortion → Decrease -x or verify 60 dB attenuation
• Frequency mismatch → Ensure -f matches receiver exactly

===============================================================================
                            4. RECEIVE/DECODE COMMANDS
===============================================================================

RX PC - Audio Playback
-------------------------------------------------------------------------------

# Listen to demodulated EAS alert audio:
rtl_fm -f 162.55M -M fm -s 24K -g 40 -l 20 -E deemp -F 0 -p 64 | aplay -r 24000 -f s16_le -c 1 -t raw

-------------------------------------------------------------------------
| Flag     | Value       | Meaning                                      |
|----------|-------------|----------------------------------------------|
| -f       | 162.55M     | Center frequency (matches TX)                |
| -M       | fm          | FM modulation mode                           |
| -s       | 24K         | Sample rate = 24 kHz                         |
| -g       | 40          | RTL gain = 40 dB (starting point)            |
| -l       | 10          | LNA gain = 10 dB                             |
| -E       | deemp       | De-emphasis filter enabled                   |
| -p       | 64          | PPM correction (run 'rtl_test -p' to calib.) |
-------------------------------------------------------------------------

RX PC - Automated Decoding
-------------------------------------------------------------------------------

# Decode SAME headers and display:
rtl_fm -f 162.55M -M fm -s 22050 -g 40 -l 20 -E deemp -F 0 -p 64 2>/dev/null | multimon-ng -t raw -a EAS - 2>&1 | grep -E "(EAS:|Decoder)"

  CRITICAL: multimon-ng EAS decoder REQUIRES 22050 Hz sample rate
    • Audio playback can use 24 kHz
    • Decode path MUST use 22050 Hz
    • Mismatch causes intermittent decode failures

===============================================================================
                            5. TROUBLESHOOTING GUIDE
===============================================================================

SYMPTOM → CAUSE → SOLUTION
-------------------------------------------------------------------------------

----------------------------------------------------------------------------------------------------
| Symptom                           | Likely Cause              | Resolution                       |
|-----------------------------------|---------------------------|----------------------------------|
| multimon-ng shows nothing         | Insufficient signal       | Verify freq; try diffrent config |
| RTL-SDR not detected              | USB/power issue           | Try different USB port           |
| EAS decode fails intermittently   | Sample rate mismatch      | Use 22050 Hz in decode path      |
| Audio too quiet/distorted         | Gain settings wrong       | Adjust -g value (start at 40)    |
| multimon-ng crashes/hangs         | Version incompatibility   | Use 1.3.0 or 1.3.1               |
| Garbled signal at correct freq    | Crystal drift (PPM error) | Add rtl_fm -p correction         |
| Intermittent signal loss          | Damaged cable/connector   | Swap cable; check SMA torque     |
----------------------------------------------------------------------------------------------------
